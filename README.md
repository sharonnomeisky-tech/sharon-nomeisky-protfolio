# Sharon Nomeisky — Portfolio

Personal portfolio site. Static, no build step.

- `index.html` — the whole site (home, Presentations, Videos, Gallery, About)
- `media/` — images and video used across the site
- `decks/` — presentation slide images
- `docs/` — CV (Hebrew / English)
- `netlify.toml` — deploy config (publish from repo root, long-cache for media)

Deployed on Netlify from this repository: every push to `main` redeploys automatically.
